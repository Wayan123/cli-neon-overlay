## Catatan publikasi

- Tidak mengklaim meningkatkan produktivitas, kompatibilitas semua terminal, atau jumlah pengguna.
- Tambahkan link bio/sticker hanya jika kamu benar-benar sudah memasangnya. Caption Instagram/TikTok tidak menjanjikan URL akan clickable.
- Cover PNG tersedia terpisah. Jika aplikasi hanya menerima pemilihan frame, pilih frame kucing sekitar detik 4.2.
- Musik tidak dibundel. Gunakan library platform dengan hak penggunaan yang sesuai jika ingin menambahkan audio.
